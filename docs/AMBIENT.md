# 幕間（まくあい）機 仕様

DJイベントなどで、ささっとつないでとりあえずの音を出す機械。
電源を入れた瞬間から、その場限りのアンビエンスが**常に鳴っている**。パラメータに触れるほど盛り上がっていく。

MAKU（docs/MAKU.md）を本体にし、それ以外の機能は大胆に捨てる。

## 原則

- 設定してから鳴らすのではない。電源を入れたら、もう鳴っている。
- 保存はしない。起動するたびに、**ランダムなパラメータ**から始まる。
- 1つのパラメータに細かく触れられることに価値はない。回せば良い方向に動くことに価値がある。
- 画面遷移もメニューもない。ボタン1つが動詞1つで、押せばすぐに音で返ってくる。

## 4つの役（トラック）

| # | 役 | 中身（MAKU） |
|---|---|---|
| 1 | 脈 | キック（DRUM） |
| 2 | 床 | ドローン（PHYS） |
| 3 | 霞 | シマー（GRAIN） |
| 4 | 声 | アルペジオのフレーズ（PHYS） |

起動時には、音源、音色、根音、スケール、テンポ（例：70〜90 BPM）、各トラックの3つのパラメータをランダムに決める。素材の幅は、残す音源の範囲（PHYS・GRAIN・DRUM、ANALOG は候補）で持たせる。

## 操作子

- **KNOB 1〜4**：トラック1〜4の**音量**。この役割は常に変わらない。
  - 少しでも回すと、そのトラックに**フォーカス**が移り、画面がそのトラックの内側になる。
- **SELECT / PRESETS / ALGORITHM**：フォーカス中のトラックの3つのパラメータ。どれも、回せば盛り上がる方向に動く。
- **MASTER**：全体の音量（ハードウェア）。
- **鍵盤**：押した音がそのまま鳴る。音はフォーカス中のトラックの声になる。スケールで補正しない。アボイドノートもスパイスとして鳴らす。

## ボタン（1つに動詞1つ）

| ボタン | 動詞 | 振る舞い |
|---|---|---|
| HOME | 振り直し | 長押しで、新しいランダムな世界に移る |
| GLO | テンポ | 押している間、SELECT が BPM になる（1刻みで1）。MIDIクロックが来ていれば追従する |
| SCL | 根音を移す | 押しながら弾いた鍵の音に、場全体の根音が移る |
| OCT− / OCT+ | 音域 | 鍵盤のオクターブを上下する |
| ARP | 回す | 押さえた鍵をアルペジオにする（トグル） |
| REC | 染み込ませる | オンの間、弾いた音を場のフレーズが拾う。アボイドノートは拾われる確率を下げる |
| SEQ | 溜める | 押している間、密度が上がるライザーになる。離すと落ちる |
| PLAY | 抜く | 押している間、キックが消える（ブレイク） |
| FX | 凍らせる | 押している間、今の響きをフリーズする |
| LFO | 掃く | 押している間、フィルターがスイープする |
| ENV | 止める | テープストップ。離すと戻る |
| SAVE | 刻む | 押している間、ビートリピートがかかる |
| EDIT | 揺らす | 押している間、ハーモナイザーとシマーが出る |

### キックにフォーカスしているとき

キックは音の高さより、鳴る位置が大事。キックのトラックにフォーカスしている間だけ、鍵盤は16ステップのシーケンサーになる。

- **白鍵16個**：ステップ1〜16。押すとそのステップがオン／オフ。ACC（黒鍵9）を押しながらだと強拍。LED は鳴るステップが点灯し、再生位置が反転して流れる。
- **手で打った拍は、常に鳴る。** 密度（SELECT）は、その上に足す「ゴースト」の確率になる。ゴーストは保存しない。
- **黒鍵1〜8**：パターン操作。左へ回す、右へ回す、反転、間引く（ランダムに1つ減らす）、足す（1つ増やす）、4つ打ち（1・5・9・13）、裏打ち（3・7・11・15）、クリア。黒鍵10・11は無機能。

## 画面：操作子の物理配置と揃えた4分割

240×240 の画面を 120×120 の4つの区画に分ける。各区画は、画面の左にある 2×2 のつまみの位置に対応させる。

```
 本体のつまみ              画面
┌────────┬────────┐   ┌──────────┬──────────┐
│ MASTER │ SELECT │   │ 波形      │ SELECT の │
│        │        │   │ BPM・音量 │ パラメータ │
├────────┼────────┤   ├──────────┼──────────┤
│PRESETS │ALGORITHM│  │ PRESETS の│ALGORITHM の│
│        │        │   │ パラメータ │ パラメータ │
└────────┴────────┘   └──────────┴──────────┘
```

- **左上（MASTER の位置）**：波形を表示する。あわせて、どのモードでも次の3つを常に表示する。
  - BPM の数字
  - 4トラックの音量を示す細いバー（KNOB 1〜4 の並びの順）
  - フォーカス中のトラック
- **右上・左下・右下**：それぞれ SELECT・PRESETS・ALGORITHM が今動かしているパラメータの名前と値。
- **すべてのモードを同じ様式で表示する。** ボタンを押している間に、3つのつまみの役割が変わるモード（GLO のテンポなど）も同じ。役割が変わったつまみの区画だけ表示が入れ替わる。
- 1つのモードに割り当てるパラメータは**最大3つ**。区画に収まらないページ送りは作らない。

## 捨てるもの

- シーケンサーの編集：STEP、ピアノロール、ドラムグリッド、パラメータロック、オートメーション、AUTO LIST、SEQ TOOLS、録音、カウントイン、メトロノーム、ソングチェーン
- 保存：プリセット、プロジェクト、RESTORE LAST、名前入力、お気に入り、バックアップ
- 音作りのページ：EDIT・ENV・LFO・MOD・ARP・CHORD・SCL の各ページ、SLICER、クイックレイヤー、メニュー
- 音源：FM6、SAMPLE、SLICE とユーザーサンプル、LOFI、WHEEL、VOICE、TRIO、PHASE、NOISE
- Web エディターとそのプロトコル

## 残すもの

- MAKU の生成ロジック、4トラックのミキサー、8ボイス、ダッキング、スケール処理
- 空間系エフェクト（リバーブ、ディレイ、コーラス）とリミッター。ただし触れるパラメータとしては出さない
- 演奏系エフェクト（リピート、テープストップ、フリーズ、フィルタースイープ、ハーモナイザー）。ボタンの動詞の中身として使う
- MIDIクロック入力（追従のみ。主役にはしない）
- ファームウェア更新の経路（ローダー、OTA、USB、インストーラー）。公式ファームウェアに戻すため必須
- ブラウザエミュレーター

## 決まったこと（実装済み）

各トラックの3つのパラメータ（1つのつまみが、最大3つの実パラメータを同時に動かす）。右に回すほど盛り上がる。

| トラック | SELECT | PRESETS（音色） | ALGORITHM |
|---|---|---|---|
| 1 脈 | DENS（密度） | TONE：TONE↑、SNAP↑、DECY↓ | WASH：リバーブ送り、ディレイ送り、DRV |
| 2 床 | OPEN：和音の声数（2〜4） | TONE：BRIT、BUZZ | SWAY：コーラス、フィルターLFO、リリース |
| 3 霞 | GRAIN：DENS↑、SIZE↓ | TONE：TONE、SPRD、RAND | AIR：リバーブ、ディレイ、アタック |
| 4 声 | LOOSE：ほどけ（再抽選）と昇り（1オクターブ上） | TONE：BRIT、DAMP↓、ACC | TRAIL：ディレイ、リバーブ、リリース |

- 起動時と HOME 長押しで、床・霞・声の音色（プリセット）と、全マクロの値がランダムに決まる。
- SEQ を押している間、密度に最大 +80 が約5秒かけて足される（ライザー）。離すと約0.25秒で落ちる。
- REC がオンの間、鍵盤で弾いた音を声のフレーズが拾う（35%）。スケール外の音は、さらに拾われにくい。
- ARP は4トラック全部のアルペジオを切り替える。
- GLO と SCL だけは、従来のレイヤーのまま（テンポ、根音）。
- HOME を押しながら OCT− を押すと、設定メニュー（色、画面オフ、キャリブレーション）が開く。メニューを閉じるのは HOME。
- CC20 は、キックの SELECT（密度）。

## 未決（実装しながら決める）

- 起動時ランダムの範囲。どこまで振れても「いい感じ」に収まるか。耳で調整が必要。
- 4つの音量を同時に上げたとき、音同士が避け合う動き（ダッキングの拡張）。
- ゴースト（密度が足すキック）を LED で暗く表示すること。
- RESTORE LAST の行、Web エディターとそのプロトコル、使わない音源の削除（実機のビルドを確かめながら）。
