# 真ん中の情景（計画。海に決めて、エミュレーターで動く）

2026-10-15。CORNERS（#style=9）の真ん中に、いま鳴っている世界を「自然の情景」で描く計画。現行の仕様は AMBIENT.md。
この文書は、決めたことと理由、いまの実装の対応表、残っていること。

## 決まったこと

- **題材は海だけ**（2026-10-14）。水辺・森の地面・海辺の3つをエミュレーターで動かして見比べ、海を残した。水辺（#style=22）と森（23）は外し、22〜24 の番号もなくした。海は #style=9 の真ん中そのもの。
- **景色は描かない。「もの」だけを描く**（2026-10-14）。空・水面・地面の塗りや窓の縁はやめ、波の線、泡、鳥、風の筋、砂だけを置く。
- **黒い面に描く**（2026-10-14）。いったん白い面（四隅の文字は濃い墨）も試したが、ほかの案と同じ黒い面に戻した。四隅の文字と弧の色も、ほかの案と同じ（`OB_*`）。
- **窓の縁は描かない**：中心から 0.7 R までははっきり、そこから R（84 px）に向かって消える。
- **季節は調（ROOT）から**：C〜D＝春、D#〜F＝夏、F#〜G#＝秋、A〜B＝冬（3音ずつ）。季節ごとに3色（深い色＝うねり、明るい色＝泡と鳥、砂の色）。マイナー系の音階（スケール 2, 3, 6, 8）は夕方の色を足す。
- **実装**：`firmware/src/ui_maku_scene.c`（`ui_maku_style3.c` が取り込む。`-DMK_STYLES` のみ。出荷ファームは不変）。描いてある画素に半透明で重ねる（画面を読み戻す）。画素ごとの場は使わない。
- モック（`tools/mk_scene_mock.py`、`docs/shots/mk_scene_seasons.png`、`mk_scene_states.png`）は、3題材を比べていたときの静止画。いまの絵とは違う（景色あり）。

### 外したものと理由

- **粒と光のにじみ（旧 `mkl_art`）**：抽象のビジュアライザーとしてよくある絵で、既存の製品と見分けがつかない。
- **水辺と森**：海がいちばん、音のパートと自然物の対応が素直だった（寄せる波＝拍、うねり＝持続、鳥＝1音ずつ、音の高さ＝飛ぶ高さ）。
- **景色の塗り**：240×240 の小さな画面では、空や地面の面が四隅の文字と弧と競合する。「もの」だけなら、黒い面の上で四隅が読みやすいまま残る。

## 0. 位置づけ（変わらない）

- **実在する自然物をデフォルメして描く**。各パートを1つの自然物にし、3つのマクロをその自然物の「様子」に割り当てる。値は量・強さ・頻度で示す（数字は四隅にある）。
- 自然物どうしが**作用し合い**、音のパートどうしの関係（キックが他を沈める、など）がそのまま絵の関係になる。
- 見て「いまどんな音か」がわかることが目的で、飾りではない。つまみを回したら、どの自然物がどう変わったかが1秒以内にわかること。
- 入れないもの：粒子、グロー、ブルーム、波形、スペクトラム（どれも既存製品の文法）。写実。人物と建物。

## 1. 配置（画面の y 座標。窓は x, y とも 36〜204）

```
   46〜95   雲の筋（霞）と鳥（声）       DRIFT の雲は y 66
  100〜164  うねりの線（床）。下ほど太く、間が開く
  144〜180  浜へ寄せる波（脈）。泡の線と、届いた所の砂の線
  170〜200  浜を走る砂（霞）
```

## 2. 4つのパート＝4つの自然物（いまの実装）

各パートの音量（KNOB 1〜4）は、その自然物の**濃さ**（0 で消える）。

| パート | 自然物 | SELECT | PRESETS（TONE） | ALGORITHM |
|---|---|---|---|---|
| 1 脈（キック） | **寄せる波**：拍ごとに浜を上って戻る（2.6 秒）。グリッドの拍は濃く、ゴーストは薄い | DENS：絵では直接使わない（拍の数がそのまま波の数になる） | **未使用** | **WASH** = 後ろに続く泡の線の本数（1〜3） |
| 2 床（ドローン） | **うねり**：横に流れる波の線 | **OPEN** = 線の本数（3〜8） | **TONE** = 線の色が深い色から明るい色へ、きらめきの短い線が増える | **SWAY** = うねりの高さ |
| 3 霞（シマー） | **風**：上の雲の筋と、浜を走る砂 | **GRAIN** = 筋の途切れ方と本数 | **TONE** = 雲の筋の色が明るくなる | **AIR** = 筋の長さと、風の強さ |
| 4 声（アルペジオ） | **鳥**：1音で1羽、左から右へ渡る | **LOOSE** = 上下に揺れる幅 | **未使用** | **TRAIL** = 鳥の後ろに引く線の長さ |

声の1音 = 鳥1羽。**音の高さ = 飛ぶ高さ**（MIDI 36〜84 を y 90〜46 に）。最大 14 羽。脈の波は同時に最大 8。

## 3. 相互作用（いまの実装）

| 作用 | 絵 | 音の側の根拠 |
|---|---|---|
| 風 → 鳥 | 風（霞の音量 × AIR）が強いほど、鳥が速く渡る | 霞が声を包む |
| 脈 → うねり・風 | キックの瞬間、うねりの線と風の筋が薄くなって戻る | **DUCK**：キックが他を沈める深さそのまま |
| フォーカス | 選んでいるパートの自然物は濃く、ほかは 78 % | つまみを回した自然物がすぐわかる |

テンポ：すべての動き（うねり、風、鳥、波）の速さが BPM に比例（78 BPM を基準に 0.55〜1.6 倍）。

## 4. 上段の6つの動詞と DRIFT（いまの実装）

| 動詞 | 出来事 |
|---|---|
| SINK（潜る） | 情景全体が薄れる（濃さ 20 % まで）。FADE の間に戻る |
| CASCADE（降り注ぐ） | 鳥の群れ（鳥が次々に入ってくる） |
| SWELL（膨らむ） | うねりが高くなる（最大 2.4 倍） |
| WOBBLE（揺れる） | 風の筋が曲がり、鳥の羽ばたきと揺れが大きくなる |
| LIFT（持ち上げる） | 真ん中に暖かい光が差す |
| SCRAMBLE（崩す） | 突風：風が強まり、筋が震え、途切れる |
| DRIFT がオン | 雲が1つ、ゆっくり横切る |

## 5. エミュレーターで見たこと（2026-10-15、`docs/shots/mk_scene_live.png`）

- 3つの世界とも、うねりの線は読める。世界ごとに線の本数と色が違うのもわかる。
- **鳥と泡が小さく、暗い**：撮影の瞬間では、鳥は数 px の点、寄せる波の泡もうっすらとしか見えない。声と脈が絵で目立たない。
- **SINK の後**：SELECT や音量を回した直後の撮影でも、まだ薄れたまま（FADE 3.8 拍の間）。動作どおりだが、つまみを回した変化が見えにくい時間がある。
- 上の1/3（雲の筋と鳥の帯）は、風が弱い世界ではほとんど空く。

## 6. 残っていること

### 見た目の調整

- 鳥の大きさと明るさ、寄せる波の泡の濃さ（5章の「小さく暗い」）。
- 静かな世界で動きが少ない。上の1/3 が空くときに何を置くか（または空けておくか）。
- 未使用のマクロ：脈の TONE（波の硬さ：低い＝丸く太い泡、高い＝細く速い線、など）、声の TONE（鳥の色）。
- 呼吸の域（BREATH_PLAN）がまだ絵にない。案：波が間遠になり、風がゆっくり往復し、色が夜へ落ちる。
- 季節の切れ目（ROOT 3音ずつ）と、調を上げ下げすると季節が巡る、という意味づけでよいか。

### 片付け

- `ui_maku_scene.c` の `sc_step` に、水辺と森のための分岐（葉が落ちて水に浮く・地面に残る、題材ごとの波紋の位置）が残っている。海だけなら不要。
- `ui_maku_style3.c` の旧 `mkl_art`（粒と光）が、どこからも呼ばれずに残っている。消してよい。
- `tools/mk_scene_mock.py` と、3題材のモック画像を残すか。

### 採用するなら

- 実機の描画時間を量る。いまは毎フレーム、浮動小数点（`sinf`、`sqrtf`）で全画面を描き、画素ごとに読み戻して混ぜる。整数化、`sinf` の表引き、動きのない時は描かない、などの間引きを実機で決める（UI_RULES 10 章：毎フレーム描画の電池への負担は未測定）。
- 追加した書体のフラッシュ容量。
- UI_RULES「左上は常にいま」の書き換え（CORNERS では左上が MASTER の扇とタイトル）。
