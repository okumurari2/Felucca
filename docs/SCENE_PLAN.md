# 真ん中の情景（計画。3題材をエミュレーターで動かした）

2026-10-14。CORNERS（#style=9）の真ん中に、いま鳴っている世界を「自然の情景のイラスト」で描く計画。現行の仕様は AMBIENT.md。
この文書は、決めたことと理由、作る順番。

## 決まったこと（2026-10-14）

- **題材は3つ作り、見比べる**：水辺 / 森の地面 / 海辺と砂。
- **窓の縁は描かない**：円の外側へ向かって背景に溶ける（輪郭線なし）。
- **季節は調（ROOT）に載せる**：C〜D＝春、D#〜F＝夏、F#〜G#＝秋、A〜B＝冬。春は桜色と若葉、夏は深緑、秋は紅葉と夕色、冬は雪（葉が雪片に、地面や砂が白に）。マイナー系は夕方の色を足す（4 章のスケールの光）。
- **3題材はエミュレーターで動く**：`#style=22` 水辺、`23` 森の地面、`24` 海辺（`firmware/src/ui_maku_scene.c`）。実装は、背景を読み戻して重ねる半透明の描画（画素ごとの場ではない）。葉・鳥は最大14、イベント（しずく・木の実・波）は最大8。
- モックは `tools/mk_scene_mock.py`（`docs/shots/mk_scene_seasons.png`、`mk_scene_states.png`）。ファームではなく、絵と対応を決めるためのもの。

### 題材ごとの自然物

| パート | 水辺 | 森の地面 | 海辺と砂 |
|---|---|---|---|
| 1 脈 | しずくと水の波紋 | 落ちる木の実と、地面に立つ土の輪 | 浜へ寄せる波（泡の線が拍ごとに上る） |
| 2 床 | 水の流れ（帯ときらめき） | 地面を這う霧（帯） | 海のうねり（帯） |
| 3 霞 | 風の筋 | 木漏れ日の筋 | 雲の筋と、浜を走る砂 |
| 4 声 | 葉（音の高さ＝枝の位置） | 落ち葉（木の上から降り、苔に残る） | 鳥（音の高さ＝飛ぶ高さ） |

マクロの割り当て（SELECT / PRESETS / ALGORITHM）は2章の表のとおり、3題材で共通の意味を持たせる：SELECT＝量・本数、PRESETS（TONE）＝明るさ・硬さ、ALGORITHM＝広がり・うねり・残り。

## 0. 位置づけ

- 粒や光のにじみ（いまの `mkl_art`）は、抽象のビジュアライザーとしてよくある絵で、既存の製品と見分けがつかない。
- 代わりに、**実在する自然物をデフォルメしたイラスト**を置く。水の流れ、風、舞う葉、しずく。
- 各パートを1つの自然物にし、3つのマクロをその自然物の「様子」に割り当てる。値は量・強さ・頻度で示す（数字や針は使わない。数字は四隅にある）。
- 自然物どうしが**作用し合う**（風が葉を運ぶ、葉が水に落ちて流される、しずくの波紋が葉を揺らす）。音のパートどうしの関係（キックが他を沈める、など）が、そのまま絵の関係になる。
- 見て「いまどんな音か」がわかることが目的で、飾りではない。つまみを回したら、どの自然物がどう変わったかが1秒以内にわかること。

### 入れないもの

- 粒子、グロー、ブルーム、波形、スペクトラム（どれも既存製品の文法）。
- 写実（240×240 の小さな画面では情報が潰れる。輪郭の少ない平面のイラストにする）。
- 人物、動物、建物（意味が強すぎる。自然物だけ）。

## 1. 情景：丸窓から見た水辺

画面中央の円（半径 約70 px。四隅の弧と扇の内側）を**丸窓**に見立て、その向こうに水辺を描く。上から：

```
        ╭───────────╮
      ╱  枝  🍃  🍃   ╲      上 1/4: 枝の先（葉が生まれる所）
     │  ～～ 風の筋 ～～  │    中 1/3: 空気（風が通る）
     │ ─────────────── │    水平線（窓の高さの 55 %）
     │ ≈≈ 流れ ≈≈ ◯ ≈≈ │    下: 水面（流れ、波紋、浮かぶ葉）
      ╲   ≈≈≈≈≈≈≈≈≈   ╱
        ╰───────────╯
```

- 水面はゆるい俯瞰（波紋は横長の楕円）。奥行きは水平線の近くほど線を細く、間を詰める。
- 窓の縁は描かない（背景に溶かす）か、細い1本の線。→ 未決（7章）。

## 2. 4つのパート＝4つの自然物

| パート | 自然物 | 音との対応の理由 |
|---|---|---|
| 1 脈（キック） | **しずく**：水面に落ちて波紋になる | 打つ・一瞬・周期。波紋の輪が拍を数える |
| 2 床（ドローン） | **水の流れ**：水面そのもの、川の流れ | 低く・持続し・全体を支える。情景の地 |
| 3 霞（シマー） | **風**：空気の筋 | 持続するが形がない、高く、空間（AIR）を担う |
| 4 声（アルペジオ） | **葉**：枝から離れ、舞い、水に落ちる | 1音ずつ生まれて消える。音の高さを位置にできる |

### マクロの割り当て

各パートの「音量（KNOB 1〜4）」は、その自然物の**存在の濃さ**（0 で消える）。3つのマクロは様子を変える。

| パート | 音量（KNOB） | SELECT | PRESETS（TONE） | ALGORITHM |
|---|---|---|---|---|
| 1 しずく | しずくの大きさ・波紋の濃さ | **DENS** = 雨の量（1滴ずつ → 小雨）。グリッドで置いた拍は大きなしずく、ゴーストは小さなしずく | **TONE** = しずくの硬さ（低い：丸く重い「ぽちゃん」、高い：細く速い「ぴっ」） | **WASH** = 波紋の広がりと残り（低い：すぐ消える、高い：何重にも広がる） |
| 2 流れ | 水面の濃さ（0：水が引いて地の色だけ） | **OPEN** = 川幅、流れの筋の本数（声数と幅） | **TONE** = 水の明るさ（低い：深い色、高い：日を返すきらめきの線が増える） | **SWAY** = 流れのうねり（低い：まっすぐ、高い：蛇行し、筋が揺れる） |
| 3 風 | 風の筋の濃さ | **GRAIN** = 風の途切れ方（低い：長く滑らかな筋、高い：短い筋が多く千切れる） | **TONE** = 風の明るさ（筋の色が地から白へ） | **AIR** = 風の高さと長さ（低い：水面すれすれ、高い：窓の上まで長く） |
| 4 葉 | 葉の大きさ・濃さ | **LOOSE** = 舞い方（低い：まっすぐ落ちる、高い：ひらひら回り、上へ戻ることもある） | **TONE** = 葉の色（低い：深緑、高い：若葉の黄緑。季節は 4 章） | **TRAIL** = 葉が水に残る時間（低い：すぐ沈む、高い：長く浮かんで流れていく） |

声の1音 = 葉1枚。**音の高さ = 葉が生まれる枝の位置**（低い音は左、高い音は右。音名は 12 か所、根音が中央）。弾いた鍵盤の音も葉になる。

## 3. 相互作用

自然物は別々に動かない。音のパートの関係を、絵の中の力にする。

| 作用 | 絵 | 音の側の根拠 |
|---|---|---|
| 風 → 葉 | 舞う葉が風の向きに流され、風が強いほど横へ運ばれる | 霞が声を包む（空間） |
| 流れ → 葉 | 水に落ちた葉が流れに乗って下流へ運ばれ、SWAY で揺れる | 床の上に声が乗る |
| しずく → 葉 | 波紋が葉の下を通ると、葉が一瞬持ち上がって揺れる | キックの拍が全体を揺らす |
| しずく → 流れ・風 | しずくが落ちた瞬間、流れの筋が一瞬沈み、風が一瞬止む（そして戻る） | **DUCK**：キックが他を沈める深さそのまま |
| 風 → 水面 | 風が強く低い（AIR 低）と、水面にさざ波（細かな短い線）が立つ | 霞と床の重なり |
| 流れ → 波紋 | 波紋は流れの方向へ少し伸び、流される | 床の上でキックが鳴る |

## 4. 全体の状態

| 状態 | 絵 |
|---|---|
| 調（ROOT） | 世界の色（空と水の色相）。新しい世界で色が替わる |
| スケール（MAJ 系 / MIN 系） | 光の向き：メジャー系は昼の光（明るく、影が短い）、マイナー系は夕方（暖色が低く、影が長い） |
| テンポ | 情景の時間の速さ（流れ・風・葉の速さがすべて BPM に比例） |
| 呼吸の域（BREATH_PLAN） | 雨が止み（しずくが減る＝キックが息に取られる）、風がゆっくり往復し、光が落ちて夜へ |
| DRIFT がオン | 窓の上を雲が1つ、ゆっくり横切る（オフで消える） |
| フォーカス中のパート | その自然物だけ色がつき、ほかは少し色が抜ける。つまみを回した自然物がすぐわかる |

### 上段の6つの動詞

動詞は「数秒効いて戻る変化」なので、情景の**出来事**にする。量（RISE / HOLD / FADE の amount）がそのまま出来事の強さ。

| 動詞 | 出来事 |
|---|---|
| SINK（潜る） | 視点が水面下へ沈む：水平線が上がり、色が深い青へ、葉は水面の裏から見える影に |
| CASCADE（降り注ぐ） | 枝から葉が一斉に降る |
| SWELL（膨らむ） | 水位が上がり、大きなうねりがゆっくり通る |
| WOBBLE（揺れる） | 風が渦を巻き、葉がくるくる回る |
| LIFT（持ち上げる） | 雲間から日が差す：明るく、きらめきが増え、影が濃くなる |
| SCRAMBLE（崩す） | 突風：風の筋が乱れ、葉が散り、雨粒が不規則になる |

## 5. 絵柄

- 平面のイラスト。輪郭線は使わず、1つの自然物を **2〜3 色の面**で描く（地色、明るい面、影）。
- 色は世界ごとに 5 色程度のパレット（空、水、葉、風、しずく）を調から作る。パートの色（mk_col の赤・黄・緑・青）は使わない（情景が記号になるため）。
- 形：
  - しずく：涙形 1 つ ＋ 波紋は横長の楕円の線（太さ 1〜2 px、外へ行くほど薄く）。
  - 流れ：水平の波線の帯を横へ流す（スクロール）。TONE が高いと、帯の上に短い明るい線（きらめき）が乗る。
  - 風：先細りの曲線（筆の払い）。始まりと終わりがかすれる。
  - 葉：アーモンド形に葉脈 1 本。回転は 8 方向 × 大小 2 の小さな絵（スプライト）を前もって作る。
- 動きは遅く。いちばん速いもの（しずくの落下）でも 0.3 秒、葉は 3〜6 秒で窓を横切る。

## 6. 実装の方針

- 場所：`firmware/src/ui_maku_style3.c` の `mkl_art` を置き換える（`-DMK_STYLES` のみ。出荷ファームは不変）。
- 状態：葉（最大 12 枚：位置、速さ、回転、水に落ちたか、残り時間）、波紋（最大 6 個）、風の筋（最大 8 本）、雲（1 つ）。毎フレーム 1 回だけ進める（画面は 2 帯で描くので、`fm1_ms` で 1 回に絞る。いまの `ma_step` と同じ）。
- 描画：画素ごとの浮動小数点の場を**やめる**（いまの `mkl_art` は 1 フレームに約 1.4 万画素を計算する）。空と水は行ごとの塗り（`cv_rect` 1 行）、流れは波線の帯、風と波紋は線、葉はスプライトの転写。実機の負担が軽く、整数に直しやすい。
- 葉のスプライト：`tools/gen_mk_fonts.py` と同じように、ビルド時に Python で作って `build/gen` に置く（8 方向 × 2 大きさ × 1 bit の形 ＋ 色は描くときに付ける。1 KB 程度）。
- 音のデータ：アルペジオの音は `maku_cur[MAKU_ARP]`、キックの拍は `maku_kick_mask()` / `maku_kick_ghosts()`、DUCK は `maku.duck`、呼吸は `maku.bb` / `maku.bw`、動詞の量は `maku.va[]`、DRIFT は `maku.dr_tog`。

## 7. 作る順番

1. **静止画のモック**（Python で PNG を数枚）：同じ世界で「静か」「賑やか」「SINK 中」「呼吸の域」を並べ、絵柄とマッピングを決める。ここで直すのが一番安い。
2. エミュレーターで動かす：流れと風 → しずくと波紋 → 葉（風と流れに乗る）→ 相互作用 → 動詞の出来事。
3. 撮影と比較：`node tools/mk_shots.mjs docs/shots/mk_scene.png 9 7,99,3`。
4. 採用するなら、実機の描画時間を量り、整数化する。

## 8. 未決

- 3題材のうち、どれを採るか（モックを見比べて決める。いずれは複数残して、世界（seed）ごとに替える手もある）。
- 季節の切れ目を ROOT の何音ずつにするか（いまは3音ずつ）。調を上げ下げすると季節が巡る、という意味づけでよいか。
- 呼吸の域の夜をどこまで暗くするか。画面は LCD なので暗くしても電力は減らない。見えるかどうか（UI_RULES 10 章の残り：暗い LCD での DIM の読みやすさ）で決める。
- 毎フレーム描くことの電池への負担（UI_RULES 10 章：波形の毎フレーム描画のコストも未測定）。動きが止まっている時は描かない、などの間引きを実機で決める。
